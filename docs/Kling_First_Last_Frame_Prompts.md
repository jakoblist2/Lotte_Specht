# Kling First & Last Frame – Lotte Specht Scrollfilm

Die kopierfertigen Produktionsprompts liegen in der visuellen Projektseite:

`dist/kling-prompts.html`

## Szenenpaare

1. Ausschluss → Idee, 5–6 Sekunden
2. Auge → Ball, 4–5 Sekunden
3. Anstoß → erstes Spiel, 6–7 Sekunden
4. Gallus Kopfball Start → Ende, 5–6 Sekunden
5. Getrennte Wege → Team, 6 Sekunden
6. Tunnel → Einlauf, 6–7 Sekunden
7. Stadion Start → Abschluss, 5–6 Sekunden

## Globale Regeln

- Hochformat 9:16
- reale Geschwindigkeit statt Zeitlupe
- Identitäten, Kleidung und Adlerposition erhalten
- pro Szene nur ein konsistenter Ball
- natürliche Nebenaktionen statt aufgestellter Statistinnen
- keine Schrift oder neu erfundenen Logos im Bild
- historische Szene: 1930, nicht 1933

## Noch benötigtes Schlüsselbild

Für „Ball landet im Tornetz“ wird ein eigener letzter Frame benötigt: Ball vollständig im Netz, Torhüterin zu spät, gleiche Flutlichtstimmung und Kameraseite wie beim Schuss.
